# Route Modules

Apply this reference when writing or reviewing the contents of a `page.tsx`, `layout.tsx`, `template.tsx`, or `default.tsx` — the modules the router instantiates directly.

## The Default Export

The router imports a route module by path and instantiates its default export. This is the one place in a codebase where a default export is not a style preference but a contract.

**Guidelines:**

- MUST give every route module a default export; a named-only export produces a route that fails to render.
- SHOULD use named exports everywhere else in the codebase, so `export default` reads as the signal that a file is router-facing.
- MUST export segment configuration (`revalidate`, `dynamic`, `runtime`, `generateStaticParams`, `generateMetadata`) as named exports beside the default one; the router reads them by name.

## Async `params` and `searchParams`

Both route inputs are promises, as the [`page.js` reference](https://nextjs.org/docs/app/api-reference/file-conventions/page) states. Synchronous access was removed in v16 — there is no compatibility shim to fall back on.

```tsx
export default async function Page(props: PageProps<"/articles/[slug]">) {
  const { slug } = await props.params;
  const { page } = await props.searchParams;
  // ...
}
```

`PageProps`, `LayoutProps`, and `RouteContext` are **globally available** type helpers generated by `next dev`, `next build`, or `next typegen`. They take a route literal and give back correctly typed params, so the route string and its parameters cannot drift apart. They are not imported.

**Guidelines:**

- MUST await `params` and `searchParams` rather than reading properties off them directly.
- SHOULD type a route module with the generated `PageProps<'/route/[param]'>` or `LayoutProps<'/route'>` helper rather than a hand-written props type, so a renamed segment becomes a type error.
- MUST run the type generator before type-checking in CI when the repository does not commit generated types; the helpers are undefined until it has run.
- MUST await `params` in `layout.tsx`, `route.ts`, `default.tsx`, and the metadata and image generation files too — the change is uniform across every convention that receives them.

## Route Parameters Are Untrusted Input

A dynamic segment is a URL component under the caller's control. It arrives typed as `string`, which says nothing about whether it is a legal identifier for the thing it will be used to look up.

```tsx
const { slug } = await props.params;
const article = await getArticleBySlug(slug); // parameterized query, validated shape
if (!article) notFound();
```

**Guidelines:**

- MUST validate or parse a route parameter before using it as a database key, a filesystem path, an outbound URL, or a redirect target.
- MUST NOT interpolate a route parameter into a query string, a shell command, or a path without the escaping its sink requires — the general injection rules belong to an application security capability, and they apply here in full.
- MUST treat `searchParams` the same way; an unvalidated `page` parameter reaching a query as a raw number is an unbounded-offset bug.
- SHOULD narrow a catch-all parameter's array shape explicitly, since `[...slug]` yields an array of arbitrary length.

## Reading Route Data from a Synchronous Component

A route module does not have to be async. A synchronous component can unwrap a promise with React's `use()`, which suspends until it resolves.

```tsx
"use client";
import { use } from "react";

export default function Page(props: PageProps<"/articles/[slug]">) {
  const { slug } = use(props.params);
  return <ArticleView slug={slug} />;
}
```

**Guidelines:**

- SHOULD prefer an async Server Component and a plain `await` when the module has no reason to be a Client Component.
- MUST use `use()` rather than `await` when the route module is a Client Component, since a client component cannot be async.
- MUST render a `use()`-consuming component inside a Suspense boundary, because it suspends.

## Layout Versus Template

A layout persists across navigations within its segment: it does not re-render, its state survives, and its effects do not re-run. A template remounts on every navigation. The default is a layout; a template is what you reach for when remounting is the point.

**Guidelines:**

- SHOULD default to `layout.tsx`, and use `template.tsx` only when a per-navigation remount is required — an enter animation, a per-page effect, or state that must reset.
- MUST NOT rely on a layout re-running to refresh data on navigation; it does not re-render, and data read there goes stale silently.
- MUST accept and render `children` in every layout, and render `<html>` and `<body>` in the root layout.
- SHOULD accept a parallel slot as a named prop on the layout that declares it, alongside `children`.

## Awaiting Request Data in a Layout

A layout wraps everything below it. Awaiting `cookies()`, `headers()`, or any uncached request data at the top of a layout body makes the whole subtree wait on it before anything can stream — the cost is paid on every route the layout covers, not just the one that needed the data.

**Guidelines:**

- SHOULD push a request-data read down into the smallest component that needs it, wrapped in its own Suspense boundary, rather than awaiting it at the top of a layout.
- MUST NOT treat a layout read of session data as an authorization boundary; see the authentication reference for why a layout check is insufficient.
- SHOULD measure before accepting a top-level layout await: it converts every covered route from static to dynamic.

**Review checks:**

- A `params` or `searchParams` property read without `await` — **Critical**; it type-errors, and where types are suppressed it silently reads `undefined`.
- A route parameter reaching a query, path, redirect, or outbound URL with no validation — **Critical**.
- A route module with no default export, or with segment config exported as part of the default object — **Critical**; the route does not work.
- An `await cookies()` or `await headers()` at the top of a widely-scoped layout — **Major**; it opts every route beneath it out of static rendering.
- A hand-written props type where the generated route-literal helper would catch a segment rename — **Minor**.
